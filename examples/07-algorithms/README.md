# 07-algorithms 运行手册

数据结构与算法领域配套可运行 TypeScript 示例。所有命令均在 **`examples/` 根目录**执行
（tsx v4.23.15，Node v24.17.0 实跑通过）。

## 一键自测

```bash
# 在 examples 目录下：顺序执行全部 10 个模块的 run()，任一断言失败立即抛错
npx tsx 07-algorithms/run-all.ts
```

末尾输出 `全部用例通过：10/10 个模块（ALGO-B1, ... ALGO-A3）`。

每个文件也可单独运行，例如 `npx tsx 07-algorithms/i1-quick-sort.ts`
（各文件末尾通过 `import.meta.url` 判断，单跑时自动执行 `run()`）。

> b1 的实测表中 O(n log n) 一列即 V8 内置 TimSort 的真实比较计数。

## 预期输出摘要（真实运行结果，数值有少量随机波动）

- **b1**：n=1k 时 O(n²) 499,500 次操作约 1.9ms，O(n log n) 8,635 次约 0.14ms；
  n=5w 时 O(n²) 理论 1,249,975,000 次、外推约 595ms，而 TimSort 714,549 次比较仅约 6ms。
- **b2**：第 1 轮 `[1,4,2,5,8]`、第 2 轮 `[1,2,4,5,8]`、第 3 轮无交换 break；已有序数组只跑 1 轮。
- **b3**：全部命中/未命中/边界用例通过；10 万规模结果与 `indexOf` 完全一致。
- **b4**：前序 `1,2,4,5,3,6`、中序 `4,2,5,1,3,6`、后序 `4,5,2,6,3,1`，递归与迭代一致；BST 中序有序。
- **i1**：6 组小数组用例正确；10 万随机数组约 8~10ms，10 万已排序数组约 2~3ms（随机基准无退化）。
- **i2**：前 3 大 `[66,78,99]`；10 万数据 Top10 与全量排序一致；数据流 Top3 = `[100,50,19]`。
- **i3**：最大深度 4；LCA(6,4)=5、LCA(6,8)=3、LCA(7,4)=2；翻转后中序序列恰好为原中序的反转。
- **a1**：依次 pop 得 `[1,2,3,5,7,8,9]`；5 万元素 pop 序列与全量排序一致；每步均断言堆序。
- **a2**：两种实现操作序列后淘汰顺序均为 `[1,4]`，get 未命中不影响顺序，capacity<=0 抛错。
- **a3**：scrollTop 0/40/150/470 → 起始索引 0/1/3/7；10 万行定位约 1 微秒；
  LIS `[1,4,2,0,3]` → 下标 `[0,2,4]`；含自引用与环的深拷贝引用一致性断言通过。
