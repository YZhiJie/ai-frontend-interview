对应 CSS-B3 优先级 四条冲突规则同时作用于同一个 <a> 元素，逐条展示四元组 (内联, id, class/伪类, 元素) 权值与最终胜出者
  • 目标元素（可悬停触发 :hover）
元素匹配链：div#header.layout > div#nav.nav > div.main > ul > li > div.content > a#target.item.title
规则选择器 a 内联b idc class/属性/伪类d 元素/伪元素 状态
甲 #header .nav .item:hover 0130
乙 #header #nav ul li a 0203
丙 .layout .main .content .title 0040
丁（补充低分规则） a.title 0011
内联 style="color: var(--orange)" 1000

比较规则（与文档答案一致）

权值记法 (a, b, c, d)
  a = 内联 style 的个数（0 或 1）
  b = id 选择器个数
  c = class / 属性选择器 / 伪类个数
  d = 元素 / 伪元素个数
  通配符 * 与组合符（>、+、~）不计权值

普通态结论：乙 (0,2,0,3) > 甲 (0,1,3,0) > 丙 (0,0,4,0) > 丁 (0,0,1,1)
  · 乙胜甲：b 位 2 > 1 —— class 数量再多也压不过一个 id
  · 甲胜丙：b 位 1 > 0
  · 从左到右逐位比较，高位相等才看下一位；四项全等时按源码顺序后者覆盖

层叠优先级链（从高到低）：
  !important 声明 > 内联 style (a=1) > (b,c,d) 普通选择器权值
  例外：后写的 !important 之间、内联 !important 之间仍按上述规则继续比较

操作提示：点按钮①，内联样式 (1,0,0,0) 直接压过四条规则；再点按钮②，丙规则带 !important 后反超内联样式。
