对应 CSS-I2 BFC BFC 是独立渲染区域：内部布局不影响外部。三个经典场景一键切换「普通态 ↔ BFC 态」对比

浮动图文字环绕 → BFC 两栏自适应

左栏 float: left 固定宽；右栏建立 BFC 后，BFC 区域不会与浮动盒重叠，自动收缩避让
float:left
固定 130px
右侧文字内容。普通态下文字会环绕浮动图片排列——注意本行开头如何钻进图片下方。 继续多写几行可以看到：只有行盒子绕开浮动区，整个内容盒其实仍与浮动区域交叠。 点击下方按钮让本区域建立 BFC（display: flow-root），它的边框会立刻收缩避让，形成清爽的两栏布局； 拖动容器右下角还能验证右栏宽度自适应。BFC 的关键规则：BFC 的区域不会与 float 盒重叠。
提示：容器右下角可拖拽改宽度（resize: horizontal），观察自适应。
普通态：文字环绕 
/* 普通态：文字环绕 */
.figure { float: left; width: 130px; }
.text   { /* 无 BFC，行盒绕开 float、盒本身仍交叠 */ }

父元素高度塌陷 → BFC 包裹浮动子元素

子元素全部浮动后脱离普通流，父元素高度坍缩为 0；父元素建立 BFC 后会把浮动子元素包裹进来
float 1
float 2
float 3
塌陷中：父高度 = 0 
/* 老式 hack */
.parent { overflow: hidden; }      /* 可能裁剪内容 / 产生滚动容器 */
/* 现代首选 */
.parent { display: flow-root; }   /* 语义化建立 BFC，无副作用 */

父子 margin 合并 → BFC 阻断合并

普通态：子元素 margin 穿透父元素；父元素建立 BFC 后，margin 被隔离在父元素内部
.child　margin: 26px 0
合并中：margin 穿透父元素 
/* 阻止父子合并：父元素建立 BFC */
.parent { display: flow-root; }
BFC 常见触发条件：根元素 html；float 非 none；position 为 absolute/fixed； display 为 flow-root / inline-block / table-cell / flex / grid；overflow 非 visible。 三个应用背后是同一原理：隔离性＋BFC 不与浮动盒重叠。
