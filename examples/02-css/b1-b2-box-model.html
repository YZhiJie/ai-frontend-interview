文档 B2 原题数值还原（width:200px / height:100px / padding:20px / border:5px / margin:10px）

box-sizing① 内容区② 实际渲染宽高（不含 margin）③ 含 margin 总占位
content-box 200 × 100 250 × 150
200 + 20×2 + 5×2 = 250；100 + 20×2 + 5×2 = 150		 270 × 170
border-box 150 × 50
200 − (20+5)×2 = 150；100 − (20+5)×2 = 50		 200 × 100（恒等于 width/height） 220 × 120

交叉验证：两种模型总占位相差 270 − 220 = 50px，恰为 (20+5)×2，即被 width「吸收」的 padding 与 border 双侧之和。margin 永远不计入 width/height，只影响元素间占位。

工程推荐写法

*, *::before, *::after { box-sizing: border-box; }
/* 让「设定尺寸 = 最终尺寸」，padding 不会撑破布局 */
