对应 CSS-A2 渲染性能 各 50 个运动方块：A 排动画 left/top（每帧重排重绘）vs B 排 transform（只合成）；rAF 实测帧率对比
Layout 重排→ Paint 重绘→ Composite 合成 开销：重排 > 重绘 > 合成；transform/opacity 动画可跳过前两阶段

A 排

el.style.left / el.style.top（几何属性）
实时 FPS -- 平均帧耗时 -- 长帧(>20ms) 0

B 排

el.style.transform = translate(x,y)（合成属性）
实时 FPS -- 平均帧耗时 -- 长帧(>20ms) 0
点击上方按钮分别运行两排（建议各跑 5 秒以上）。对比要点：A 排每帧触发 Layout + Paint + Composite； B 排的 transform 由合成器线程处理，理论上只走 Composite 一阶段。机器性能越强绝对差越小， 可勾选「大模糊 box-shadow」放大 Paint 成本、「两排同时跑」加大压力后再比。

优化清单（文档答案要点）

/* 1. 动画只用合成属性 */
@keyframes move { from { transform: translateX(0); } to { transform: translateX(300px); } }
/* 避免 width/height/left/top 动画 */

/* 2. will-change 是「契约」不是银弹：只给即将动画的少量元素，结束后移除 */
.animating { will-change: transform; }   /* 几百个常驻 → 合成层爆炸：显存/纹理上传暴涨 */

/* 3. 规避大面积 paint：降低 box-shadow 模糊半径、缩小绘制区、伪元素预渲染 */
/* 4. content-visibility: auto 跳过屏外渲染；contain: strict 限制重排范围；虚拟列表减少节点 */
/* 5. 量化：Performance 面板看 FPS 曲线；Paint flashing 下绿色重绘区应显著减少；目标稳定 60 FPS */
