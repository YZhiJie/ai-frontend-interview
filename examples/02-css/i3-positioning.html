顶部导航 fixed

相对视口定位、脱离文档流，滚动时始终钉在顶部；body 用 padding-top:56px 补偿它的占位，否则正文被遮挡。

.nav { position: fixed; top: 0; left: 0; right: 0; height: 56px; z-index: 100; }

左侧目录 sticky

不脱离文档流、保留占位；滚动到 top:56px（导航下沿）后吸附。失效陷阱：任意祖先 overflow 非 visible/clip、父容器比它矮、或没设 top。

.sidebar { position: sticky; top: 56px; height: calc(100vh - 56px); }

正文区 static

常规流零成本，天然充当 sticky 侧栏的滚动祖先，只需 padding-top 补偿 fixed 导航。

relative 原位偏移实验 static

relative 保留原占位，只做视觉偏移；更重要的价值是充当 absolute 子元素的包含块（见客服角标）。

这行文字中有一个 #marker 标记，点击按钮在 static / relative(top:-8px; left:14px) 间切换：注意它偏移后原来的位置仍然留空，后续文字不会补位。

右下角客服按钮 fixed + 角标 absolute

FAB 为 fixed 时相对视口、滚动不动；切成 absolute（本页无定位祖先）后相对初始包含块，向下滚动它会随文档滚走。红色角标始终 absolute 锚定在按钮右上角。

长文段落 1

向下滚动：导航保持在顶部（fixed），左侧目录滚动到导航下沿后吸顶跟随（sticky），而本内容区正常随文档滚动（static）。

占位文字……布局定位的取舍核心就两点：是否脱离文档流、包含块是谁。fixed/absolute 脱离文档流要自己补偿占位；sticky 不脱离、保留占位；relative 也保留占位只做视觉偏移。

长文段落 2

观察右下角客服按钮的两种表现：fixed 时它无视滚动；absolute 时它属于页面坐标，会被滚出视口。角标用 absolute 相对按钮（按钮在两种模式下都是定位元素）定位。

占位文字……sticky 的吸顶依赖最近滚动祖先；本页 body 滚动、侧栏父级 flex 容器没有 overflow 裁剪，所以 sticky 正常工作。

长文段落 3

继续滚到底部，可以验证 sticky 元素受父容器高度约束——侧栏跟随整个 .layout 容器，容器结束它也结束。

占位文字……absolute 滥用容易导致布局碎片化：它完全脱离文档流，相对最近的定位祖先偏移，因此父级必须被正确「定位化」（relative 最常用）。

五种定位取舍总结

static   常规流，top/right/bottom/left 与 z-index 无效
relative 常规流原位 + 视觉偏移，占位保留；常作 absolute 的包含块
absolute 脱离文档流，相对最近「定位祖先」偏移，无则相对初始包含块
fixed    脱离文档流，相对视口（弹窗/导航/悬浮按钮），需补偿占位
sticky   不脱离文档流，跨过 top 阈值前为 relative、之后表现为 fixed 吸附
