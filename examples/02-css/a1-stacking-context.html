对应 CSS-A1 层叠上下文 z-index:9999 的弹窗为何被 z-index:2 的兄弟盖住？一键移除父容器 transform，观察「封闭空间」被打破

经典复现：.child z-index:9999 vs .rival z-index:2

两个色块的重叠区域，谁在上？
.parent { position:relative; transform:translateZ(0); z-index:auto }
.child（弹窗） position:absolute; z-index:9999
.rival（兄弟元素） position:relative; z-index:2 

    


    

      
同一层叠上下文内：七层绘制顺序（底 → 顶）

      
先画的在底，后画的在上；z-index 只在同一上下文内部比较

1层叠上下文根元素的背景与边框

7正 z-index 的子层叠上下文（由小到大）—— .rival z-index:2 在此层

      

    

  


  
层叠上下文常见形成条件（排查层级冲突的第一步）

  

    
    
      
  • ① 根元素 html
    • 
      
  • ② position 非 static 且 z-index 非 auto
    • 
      
  • ③ flex / grid 子项且 z-index 非 auto
    • 
      
  • ④ opacity < 1
    • 
      
  • ⑤ transform / perspective / filter / mask 非 none（本例即 transform: translateZ(0)）
    • 
      
  • ⑥ will-change 声明了可形成上下文的属性
    • 
      
  • ⑦ isolation: isolate、mix-blend-mode 非 normal 等
    • 
    

    

      结论：层叠上下文是封闭空间——子元素的 z-index 无法逃逸。排查时先确认两个冲突元素是否属于同一层叠上下文，而不是盲目调大 z-index。
