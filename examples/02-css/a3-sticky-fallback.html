现代浏览器全量支持 sticky（Chrome 91+/Edge 79+/Firefox 32+/Safari 6.1+ 需前缀）；左侧降级按钮可随时手动模拟旧浏览器路径。

② 两个最常见失效陷阱

  • 任意祖先元素 overflow: hidden/auto/scroll（非 visible/clip）会让 sticky 失效或行为异常；
  • sticky 受父容器高度约束（父容器必须比它高），且 top 必须显式设置，否则不吸附。

@supports 特性检测与 static 基线

.table-head {
  position: -webkit-sticky; /* 老版 Safari 需要，Autoprefixer 也会自动补 */
  position: sticky;
  top: 56px;
}
/* 不支持时走 static 基线：表格功能完整，只是不吸附 */
@supports not ((position: sticky) or (position: -webkit-sticky)) {
  .table-head { position: static; }
}

JS 降级思路（rAF 节流 + 等高占位）

let ticking = false;
box.addEventListener('scroll', () => {
  if (!ticking) {
    ticking = true;
    requestAnimationFrame(() => {
      const boxRect = box.getBoundingClientRect();
      sections.forEach(sec => {
        const head = sec.querySelector('[data-head]');
        const shim = sec.querySelector('[data-shim]');
        const headRect = head.getBoundingClientRect();
        const secBottom = sec.getBoundingClientRect().bottom - boxRect.top;
        const crossed = headRect.top - boxRect.top <= 0 && secBottom > headRect.height;
        head.classList.toggle('is-fixed', crossed);   // fixed + top/left/width 按容器换算
        shim.classList.toggle('on', crossed);          // 等高占位，防止内容跳动
        shim.style.height = crossed ? headRect.height + 'px' : '0px';
      });
      ticking = false;
    });
  }
});
/* 降级脚本仅在特性检测失败时按需加载，符合「核心体验优先、增强体验分层」 */
