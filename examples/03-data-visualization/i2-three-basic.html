五类基本对象职责

Scene 场景承载所有 3D 对象的根容器
PerspectiveCamera由 fov / aspect / near / far 定义视锥体
WebGLRenderer创建 WebGL 上下文，把场景逐帧绘制到 canvas
Light ×2AmbientLight 环境底色 + DirectionalLight 平行光产生方向明暗
MeshBoxGeometry + MeshStandardMaterial（PBR，需光照才可见）
GridHelper地面参考网格，体现空间与立方体悬浮位置

关键代码（r128 UMD 全局 THREE 兼容写法）

// 1-3. 场景 / 透视相机 / 渲染器
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, w / h, 0.1, 100);
camera.position.set(3, 3, 5);
camera.lookAt(0, 0, 0);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setPixelRatio(Math.min(devicePixelRatio, 2)); // 限制 DPR，避免高分屏过度绘制
renderer.setSize(w, h);
host.appendChild(renderer.domElement);

// 4. 环境光（0.4）+ 平行光（1.0）
scene.add(new THREE.AmbientLight(0xffffff, 0.4));
const dir = new THREE.DirectionalLight(0xffffff, 1);
dir.position.set(5, 8, 5);
scene.add(dir);

// 5. 绿色立方体 + 地面网格
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(2, 2, 2),
  new THREE.MeshStandardMaterial({ color: 0x2ecc71 })
);
scene.add(cube);
scene.add(new THREE.GridHelper(12, 12, 0x334155, 0x1e293b));

// 6. rAF 渲染循环（与刷新率对齐、页面隐藏自动暂停）
(function animate() {
  requestAnimationFrame(animate);
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
})();

// 7. resize 三件套：aspect → updateProjectionMatrix → setSize
window.addEventListener('resize', () => {
  camera.aspect = host.clientWidth / host.clientHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(host.clientWidth, host.clientHeight);
});
