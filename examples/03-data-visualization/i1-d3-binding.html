初始渲染：页面无 circle，3 个数据全部进入 enter 集（对应文档示例）。

enter 集

数据多、节点少 → enter().append('circle') 补建（绿色弹出）

update 集

数据与节点都已存在（按 key 匹配）→ 更新 cx/r（青色高亮后归一）

exit 集

节点多、数据少 → 冗余节点必须显式 remove()（橙色缩小消失）

merge 集

.merge(update) 合并 enter 与 update，统一设置属性，避免写两遍

本演示使用 key 函数 .data(arr, d => d.id)：打乱顺序时节点按身份复用、移动到新位置，而不是按索引错位。

核心代码（General Update Pattern）

const svg = d3.select('#svg');

function render(data) {
  // 1. 绑定：第二个参数是 key 函数，按 id 而非索引划分三集
  const circles = svg.selectAll('circle').data(data, d => d.id);

  // 2. exit：先标记成橙色，过渡缩小后必须 remove
  circles.exit()
    .attr('fill', '#f97316')
    .transition().duration(500).attr('r', 0).attr('opacity', 0)
    .remove();

  // 3. enter：补建节点，r 从 0 弹出
  const entered = circles.enter().append('circle')
    .attr('cy', H / 2).attr('r', 0).attr('fill', '#34d399')
    .attr('cx', (d, i) => 40 + i * 64)
    .transition().duration(500).attr('r', d => d.v / 2);

  // 4. merge：enter + update 统一设置位置 / 半径 / 颜色
  entered.merge(circles)
    .transition().duration(500)
    .attr('cx', (d, i) => 40 + i * 64)
    .attr('r', d => d.v / 2)
    .attr('fill', '#a78bfa');   // 文档原例为 steelblue
}

select/selectAll 与 datum/data

select 返回第一个匹配节点（容器级操作）；selectAll 返回全部匹配节点（批量绑定的基础）。
datum 给每个节点绑同一个静态值，不产生 enter/exit；data 按索引或 key 函数逐一绑定数组并划分三集。
